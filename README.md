# 美光

一邊用手機螢幕補光，一邊影相同拍片。適合自拍、化妝同補光拍攝。

## 使用

打開這個頁面：[https://carloscklckl.github.io/meiguang/](https://carloscklckl.github.io/meiguang/)

- 建議用手機瀏覽器，並將系統亮度開到最高
- 第一次使用要允許相機（同埋拍片時的麥克風）
- 可以加到主畫面，當獨立 app 使用
- 需要 HTTPS；用瀏覽器直接開檔案會無法啟動相機

## 功能

- 螢幕補光：色溫、亮度、範圍，以及冷白、自然、暖陽、象牙、粉光等預設
- 相機：影相、拍片、前後鏡頭、閃光／手電筒、對焦、縮放、倒數、連拍、比例同網格
- 濾鏡、自拍鏡像、自拍螢幕閃光、相簿同分享

瀏覽器同系統限制：無法做到人像景深、夜景模式或 ProRAW；iPhone 上部分閃光、對焦同縮放功能可能不可用。
